# Design notes

Free-form supporting material for specs: exploratory research, benchmark evidence,
diagrams, and throwaway analysis. Unlike [specs](../specs/), notes are **not**
schema-governed and **not** tracked in the [ledger](../LEDGER.md).

Convention: name notes `NNNN-slug.md` matching the spec they support (e.g.
`0001-xdg-migration-evidence.md`), or use a descriptive slug for standalone research.

The original prototype scripts (`prototype_report.py`, `analyze_probe.py`) are the
historical evidence that the passive-tracking model works; their findings are summarized
in the README's *How time is calculated* section. Future evidence-gathering scripts can
be parked here rather than at the repo root.

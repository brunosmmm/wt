# Clock

Supplemental **intentional wall-time** on an idea while you build a slice.

## What it is not

It does **not** replace passive transcript hours — clocking is supplemental. Passive tracking still comes from
Claude/Cursor/meetings — see [Report & topics](report.md) and the [home](../index.md)
narrative.

## Commands

```bash
wt idea clock-in IDEA-00N
wt idea clock-out IDEA-00N
```

Desk: toggle with key `i` on the selected idea ([Desk](tui.md)). Open clocks show `◕`
beside the id in CLI idea tables.

Use during implementation sessions (AGENTS.md / SPEC-0060): every clock-in needs a
matching clock-out before you stop.
